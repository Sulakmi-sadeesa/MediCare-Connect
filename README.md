A modern, responsive healthcare platform for Medi House, giving patients easy access to doctors, appointments, reports, and AI assistance. Built with a **shared SQL database** alongside the Staff Website.

## 🎯 System Structure
- **Patient Website** – Register (via Reception only), Doctors, Booking
- **Staff Website** – Reception, Doctor, X-ray, Scan, Lab, Admin

## 🎨 Design
- **Primary Color:** Dark Blue
- Creative, user-friendly, comfortable UI
- Fully responsive (mobile + desktop)

## 🧑‍⚕️ Public Pages
- **Home** – Logo, nav, About, Services, Doctors, Departments, AI Assistant, Contact, Login, My QR. Hero: *"Your Health, Our Priority"* → View Doctors | Explore Services
- **About** – History, Mission/Vision, Facilities, Departments, Hours, Location, Contact
- **Doctors** – Photo, Name, Specialization, Department, Days, Time, Experience, View Profile
- **Doctor Profile** – Qualifications, Sessions, Consultation fee
- **Services** – General Consultation, Dental, Scanning, Laboratory
- **Service Details** – Types, Descriptions, Preparation, Hours, Location
- **Public AI Assistant** – Answers general questions; asks login for personal info

> ⚠️ Registration is done **only via Reception** — not on the website.

## 🔐 Patient Dashboard (After Login)
| Section | Contents |
|---|---|
| **Dashboard** | Welcome, Patient ID, QR access, Upcoming appointment, Channel status, Reports, Payments, AI shortcut |
| **My QR** | Large QR, Patient ID, Name, Status, Download, Instructions |
| **Appointments** | Tabs: Upcoming / Completed / Cancelled — View, Reschedule, Cancel |
| **Channel Status** | Your channel, Now serving, Patients ahead, Est. waiting time |
| **Medical Reports** | Lab, X-ray, Scan, Dental, Other — View / Download |
| **Prescriptions** | Doctor, Date, Diagnosis, Medicine, Dosage, Duration, Instructions |
| **Payments** | Service, Doctor, Date, Amount, Method, Status, Receipt |
| **Profile** | Personal info, Emergency contact, Edit, Change Password |
| **AI Assistant** | Chat, Voice input, Suggested questions, Personalized responses |

## 🔄 Navigation Flow
**Before Login:**
Home → About → Doctors → Services → Departments → Public AI → Contact

**After Login:**
Dashboard → My QR → Appointments → Channel Status → Reports → Prescriptions → Payments → Profile → AI Assistant

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JS (or React/Next.js)
- **Backend:** Node.js / PHP / Python
- **Database:** MySQL / SQL Server (shared with Staff Website)

## 📱 Responsive
Optimized for both **mobile phones** and **laptops/desktops**.

> **Note:** Staff Website (Reception, Doctor, X-ray, Scan, Lab, Admin) is documented separately and shares the same SQL database. Website** – Reception, Doctor, X-ray, Scan, Lab, Admin
